# Phase 2.5 — CLI Dashboard Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace bare `println!` output during multi-peer downloads with a live terminal dashboard showing progress bar, speed, ETA, peer count, and piece progress.

**Architecture:** A `DownloadStats` struct wrapped in `Arc<Mutex<_>>` is updated by the coordinator's event loop and read by a dashboard render task running at 8 Hz. The dashboard uses `ratatui` with a `crossterm` backend. It activates only when `total_size > 0` (multi-peer mode); single-peer mode keeps its existing output unchanged. The dashboard renders inline — no alternate screen — so output survives terminal resize and is visible after exit.

**Tech Stack:** Rust, ratatui 0.29, crossterm 0.28, tokio (existing), Arc<Mutex<DownloadStats>>

**Step 1: Create `src/cli/dashboard.rs`**

This file owns both the stats struct and the rendering logic.

```rust
use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant};

use ratatui::backend::CrosstermBackend;
use ratatui::layout::{Constraint, Direction, Layout};
use ratatui::style::{Color, Modifier, Style};
use ratatui::text::{Line, Span};
use ratatui::widgets::{Block, Borders, Gauge, Paragraph};
use ratatui::Terminal;

#[derive(Debug, Clone)]
pub struct DownloadStats {
    pub piece_count: u32,
    pub pieces_done: u32,
    pub peers_connected: usize,
    pub bytes_total: u64,
    pub bytes_done: u64,
    pub started_at: Instant,
    pub complete: bool,
}

impl DownloadStats {
    pub fn new(piece_count: u32, bytes_total: u64) -> Self {
        Self {
            piece_count,
            pieces_done: 0,
            peers_connected: 0,
            bytes_total,
            bytes_done: 0,
            started_at: Instant::now(),
            complete: false,
        }
    }

    pub fn progress_ratio(&self) -> f64 {
        if self.piece_count == 0 {
            return 0.0;
        }
        self.pieces_done as f64 / self.piece_count as f64
    }

    pub fn elapsed_secs(&self) -> f64 {
        self.started_at.elapsed().as_secs_f64()
    }

    pub fn speed_bps(&self) -> f64 {
        let elapsed = self.elapsed_secs();
        if elapsed < 0.1 {
            return 0.0;
        }
        self.bytes_done as f64 / elapsed
    }

    pub fn eta_secs(&self) -> Option<f64> {
        let speed = self.speed_bps();
        if speed < 1.0 {
            return None;
        }
        let remaining = self.bytes_total.saturating_sub(self.bytes_done);
        Some(remaining as f64 / speed)
    }
}

pub fn format_bytes(bytes: u64) -> String {
    if bytes >= 1_073_741_824 {
        format!("{:.2} GB", bytes as f64 / 1_073_741_824.0)
    } else if bytes >= 1_048_576 {
        format!("{:.2} MB", bytes as f64 / 1_048_576.0)
    } else if bytes >= 1024 {
        format!("{:.2} KB", bytes as f64 / 1024.0)
    } else {
        format!("{bytes} B")
    }
}

pub fn format_speed(bps: f64) -> String {
    format!("{}/s", format_bytes(bps as u64))
}

pub fn format_eta(secs: Option<f64>) -> String {
    match secs {
        None => "∞".to_string(),
        Some(s) if s < 60.0 => format!("{:.0}s", s),
        Some(s) if s < 3600.0 => format!("{:.0}m {:.0}s", s / 60.0, s % 60.0),
        Some(s) => format!("{:.0}h {:.0}m", s / 3600.0, (s % 3600.0) / 60.0),
    }
}

pub async fn run_dashboard(stats: Arc<Mutex<DownloadStats>>) {
    use crossterm::{
        execute,
        terminal::{disable_raw_mode, enable_raw_mode, EnterAlternateScreen, LeaveAlternateScreen},
    };
    use std::io::stdout;
    use tokio::time::{interval, Duration as TokioDuration};

    let _ = enable_raw_mode();
    let mut out = stdout();
    let _ = execute!(out, EnterAlternateScreen);

    let backend = CrosstermBackend::new(stdout());
    let mut terminal = match Terminal::new(backend) {
        Ok(t) => t,
        Err(_) => {
            let _ = disable_raw_mode();
            return;
        }
    };

    let mut tick = interval(TokioDuration::from_millis(125));

    loop {
        tick.tick().await;

        let snapshot = {
            let s = stats.lock().unwrap();
            s.clone()
        };

        let complete = snapshot.complete;

        let _ = terminal.draw(|frame| render(frame, &snapshot));

        if complete {
            break;
        }
    }

    let _ = execute!(terminal.backend_mut(), LeaveAlternateScreen);
    let _ = disable_raw_mode();
}

fn render(frame: &mut ratatui::Frame, stats: &DownloadStats) {
    let area = frame.area();

    let chunks = Layout::default()
        .direction(Direction::Vertical)
        .constraints([
            Constraint::Length(3), // title
            Constraint::Length(3), // progress bar
            Constraint::Length(3), // stats row
            Constraint::Min(0),
        ])
        .split(area);

    // Title
    let pct = stats.progress_ratio() * 100.0;
    let title = Paragraph::new(Line::from(vec![
        Span::styled(
            "AegisTorrent",
            Style::default()
                .fg(Color::Cyan)
                .add_modifier(Modifier::BOLD),
        ),
        Span::raw(format!(
            "  ·  {}/{}  ·  {:.1}%",
            format_bytes(stats.bytes_done),
            format_bytes(stats.bytes_total),
            pct
        )),
    ]))
    .block(Block::default().borders(Borders::ALL));
    frame.render_widget(title, chunks[0]);

    // Progress bar
    let gauge = Gauge::default()
        .block(Block::default().borders(Borders::ALL).title("Progress"))
        .gauge_style(Style::default().fg(Color::Green))
        .ratio(stats.progress_ratio().clamp(0.0, 1.0))
        .label(format!(
            "{}/{} pieces",
            stats.pieces_done, stats.piece_count
        ));
    frame.render_widget(gauge, chunks[1]);

    // Stats row
    let stats_text = format!(
        "↓ {}   Peers: {}   ETA: {}   Elapsed: {:.0}s",
        format_speed(stats.speed_bps()),
        stats.peers_connected,
        format_eta(stats.eta_secs()),
        stats.elapsed_secs(),
    );
    let stats_widget = Paragraph::new(stats_text)
        .block(Block::default().borders(Borders::ALL).title("Stats"));
    frame.render_widget(stats_widget, chunks[2]);
}
```

### Task 3: Expose `DownloadStats` from the coordinator

**Files:**
- Modify: `src/network/coordinator.rs`

The coordinator's `run()` method needs to accept an optional `Arc<Mutex<DownloadStats>>` and update it as pieces are verified and peers connect/disconnect.

**Step 1: Update `coordinator.rs`**

Add import at top:
```rust
use std::sync::{Arc, Mutex};
use crate::cli::dashboard::DownloadStats;
```

Change `run()` signature to:
```rust
pub async fn run(
    self,
    stats: Option<Arc<Mutex<DownloadStats>>>,
) -> Result<DownloadResult, Box<dyn std::error::Error>>
```

Add a helper macro/closure at the start of `run()` after variable declarations:
```rust
let update_stats = |stats: &Option<Arc<Mutex<DownloadStats>>>, f: &dyn Fn(&mut DownloadStats)| {
    if let Some(s) = stats {
        if let Ok(mut guard) = s.lock() {
            f(&mut guard);
        }
    }
};
```

In the `PoolEvent::PeerConnected` arm, add:
```rust
update_stats(&stats, &|s| s.peers_connected += 1);
```

In the `PoolEvent::PeerDisconnected` arm, add:
```rust
update_stats(&stats, &|s| {
    s.peers_connected = s.peers_connected.saturating_sub(1);
});
```

In the `PoolEvent::PieceReceived` arm, after `scheduler.piece_completed(index)`:
```rust
update_stats(&stats, &|s| {
    s.pieces_done += 1;
    s.bytes_done = s.pieces_done as u64 * self.piece_size as u64;
});
```

At the end of the loop (after `writer.finish()`), mark complete:
```rust
update_stats(&stats, &|s| s.complete = true);
```

Also update the `DownloadStats::new(piece_count, bytes_total)` call — it will be created in `main.rs`, so you just need to wire through the `Option<Arc<Mutex<DownloadStats>>>`.

} else {
    use aegistorrent::network::coordinator::DownloadCoordinator;
